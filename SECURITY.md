# Security

WISE can run commands, edit files, use browsers and external services. Use a dedicated workspace, loopback-only API, authentication before remote exposure and review of high-impact actions. Model instructions are not access controls.

Never commit tokens, credentials, browser storage, private recordings or runtime state. Separate service/profile secrets. Administrative actions require official UAC consent; bypass is unsupported.

Use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner privately. Do not put credentials, private logs or exploits against other people's services in public issues. Non-sensitive bugs may use the issue template with versions and redacted reproduction details.

Development preview: no supported stable release or guarantee of safe unattended operation yet.
