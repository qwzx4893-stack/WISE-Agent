# WISE: verified repair and catalog maintenance — 2026-10-01

## Delivered

- Raw shell/Python entry points require SecurityGate authorization, including direct builtin calls. Untrusted content cannot authorize them. Failed commands return failures, not successful capabilities.
- Application launches no longer interpolate targets into `cmd /c start` or `shell=True`. Normal executable arguments still work; interpreter launches require authorization.
- No WAIT-only placeholder success. Malformed routing does not invent desktop actions. Unsupported plans request clarification. Research entities, comparisons and budget filtering no longer use fabricated fixtures or fixed prices.
- Web fetch rejects local-file/custom schemes and limits reads. Archive extraction rejects escaping paths and symlinks. Academic XML uses a hardened parser.
- OpenRouter-style secrets are scrubbed from memory and audit text. MCP child processes inherit only a system environment allowlist, not provider keys. Context7 queries are scrubbed before transmission.
- Canonical memory replaces the duplicate, auto-loading Chroma/embedding path. Existing Chroma databases were preserved, not deleted or silently migrated. Semantic skill search remains opt-in.
- Small-window composer/wordmark clipping and the observed text contrast failure are fixed without redesigning the interface.
- Tests now use an isolated skills copy, preventing test uploads/caches from changing the user's catalog.

## Readiness limits
